# Obsidian 正文插图

从目标库同组的一篇成品确认笔记格式、图注写法和附件目录。保留原有标签、日期和脚注，在相关正文段落之后、译注之前嵌图。附件目录沿用用户指定库的设置。选篇清单、提示词、校对图和工作脚本留在库外。

## 一幅图如何落位

1. 记录目标笔记的库内完整路径，再从正文复制能唯一定位该段的短句。前置属性、编者注、页末译注里的同一句话不算图位。若一个自然段很长，可选紧邻的短段作为引子。
2. 将定稿原图复制到约定目录。沿用「篇名-画名.png」这种可辨识的名字，或服从用户的命名规则。遇到同名文件先比较内容；已有其他成品时另取新名。“补齐”先查已有嵌图，按实际缺图的篇目继续。
3. 从定位短句读到这个 Markdown 自然段的末尾。两行正文之间只有一个换行时，它们仍是同一段；下一行是空行或文档结束时，才到这个正文段落的末尾。在最后一行之后留一空行写嵌图，再留一空行写斜体图注。图注写明是据日记创作的 AI 插画。书名、日期以本篇为准。日期不详时可据篇名署记，约略日期照录“大约”或“约”。

```md
![[附件/雨后-碗底的光.png]]

*《碗底的光》｜据日记《雨后》创作，AI 绘制。*
```

## 可用的插图助手

桌面 Obsidian 已打开且可以执行应用内 JavaScript 时，可从安装目录加载 [scripts/embed.cjs](../scripts/embed.cjs)。调用前先将成品图片存入目标库。用指定库的应用上下文执行，路径用库内完整路径、正斜杠，`caption` 传入含 Markdown 斜体标记的完整一行。示例中的日记与附件使用虚构路径。请把模块路径、笔记路径、附件路径及定位短句替换为现场值。

```js
const embed = require('/absolute/path/to/tangerine-cat-diary-illustrations/scripts/embed.cjs');
await embed(app, {
  notePath: '日记/雨后.md',
  imagePath: '附件/雨后-碗底的光.png',
  anchor: '我把蓝碗放回窗台',
  caption: '*《碗底的光》｜据日记《雨后》创作，AI 绘制。*',
  apply: false
});
```

示例默认预览图位。需要写入时设为 `apply: true`。助手只在正文段落中匹配，允许定位短句跨过脚注标记；再次运行会识别已有嵌图。图位有歧义就换更准确的短句。正文并发变动时重新读取。正文是列表、引用等特殊结构时，依实际块结构直接插图。桌面接口不可用时也可以在原 Markdown 中做相同的局部插入。

## 回读

逐篇核对图位、署名和附件可读性，比较插图前后的正文、属性与译注。直接编辑 Markdown 时，临时从结果中去掉本次新增的嵌图块并逐字比对原稿，连同原有空行和文件末尾的换行一起核对。批量续作时也核对原有样张。可访问 Obsidian 时，通过当前库的元数据解析嵌图目标并加载图片；仅做了文件检查时按实际验证范围说明。
